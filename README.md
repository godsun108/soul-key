# SOUL KEY

A falsifiable presence-recognition and identity research lab.

> Build the rules. Hide the answer. Predict. Freeze. Reveal reality.

SOUL KEY asks whether an enrolled person can be recognized from measured signals under progressively stricter controls. It does **not** assume a soul, consciousness field, quantum identity, or unknown physics exists.

## Two planes

**Security plane:** established cryptography, passkeys/hardware-backed keys, challenge/signature authentication. This plane alone may eventually authorize a wallet.

**Research plane:** blinded PRESENT / OTHER / EMPTY trials, sensor ablation, frozen predictions, commit/reveal evidence, and prospective scoring. Research output cannot authorize funds.

## The ladder

We begin with deliberately easy recognition and progressively remove information:

1. full conventional sensors;
2. no face;
3. no voice;
4. no device/network identifiers;
5. environmental/physiological channels only;
6. isolated experimental channels;
7. documented QRNG channel;
8. prospective replication;
9. independent replication.

A result only advances if it survives its frozen gate. Failure is preserved.

## v0.1

The credential-free core provides:

- deterministic blinded schedules;
- commit/reveal labels;
- feature fingerprints;
- prospective predictions;
- multiclass Brier + accuracy scoring;
- hash-chained evidence ledger;
- sensor-channel declarations and ablation plans;
- synthetic end-to-end rehearsal;
- CI tests.

No third-party Python packages are required.

```bash
python -m unittest discover -s tests -v
python experiments/synthetic_presence.py
```

**No experimental signal is a private key. No anomaly is proof of a soul.**
